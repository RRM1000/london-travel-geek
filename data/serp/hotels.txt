# Hotel sources, SERP-seeded 2026-09-09 per data/serp/README.md.

# Rob's rule for this corpus: evidence comes from guides and especially
# BLOGGERS. Booking engines are not sources - Booking.com, Hotels.com, Expedia,
# Tripadvisor, Agoda, Hostelworld and the rest rank by inventory and commission,
# so a listing there says nothing about whether anyone rates the place.
#
# Hotels.com has one job in this pipeline and it is the opposite one: once a
# property has been NAMED by a source here, check it exists and is bookable on
# Hotels.com, because a property that is not cannot carry an affiliate link.
# Validator, never a source.
#
# Brand sites are excluded for the same reason as the OTAs - premierinn.com
# listing its own hotels is not a recommendation.
