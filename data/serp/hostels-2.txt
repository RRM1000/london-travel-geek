# Hostel sources, second corpus. SERP-seeded 2026-09-09 in the browser, per
# data/serp/README.md and data/reference/hotel-corpus.md.
#
# The `hostels` topic (data/serp/hostels.txt) holds four backpacker blogs and
# yielded only a handful of names. This is the widening pass over the same
# search, not a replacement - the two topics are scored separately.
#
# Rob's rule for this corpus: evidence comes from guides and especially
# BLOGGERS. Booking engines are not sources - Hostelworld, Booking.com,
# Hostelz, Agoda and the rest rank by inventory and commission, so a listing
# says nothing about whether anyone rates the place. Brand sites are out for
# the same reason: a hostel group listing its own beds is not a recommendation.
#
# That rule does most of the work here, because "best hostels in London" is a
# SERP almost entirely owned by Hostelworld affiliates. Of nineteen domains the
# search returned, six survived.
#
# ---------------------------------------------------------------------------
